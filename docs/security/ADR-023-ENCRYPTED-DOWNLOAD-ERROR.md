# ADR-023：加密附件失败必须是失败的传输

状态：ACCEPTED，2026-10-29；SEC-052-A；基线8c39931733be853dd68d11ad5b193088c4d928d5。
覆盖本地服务器解密下载与现有浏览器WASM流错误传播，不改变密码、密钥封装、ciphertext、E2E协议或存储格式。

## 不变量与选择

密钥元数据检查只是前置检查，不能代替完整流认证。该密钥前置检查失败返回HTTP 500且无附件头；
认证流已开始后失败不向文件正文追加错误文本，也不能正常结束响应。采用Go标准http.ErrAbortHandler，
由net/http关闭H1连接或重置H2流；不能通过return false引导外层在已发送正文后再重定向。
头可能已发送为200，正确失败证据是客户端传输错误及未进入成功终态，而不是强行改写已发送的状态码。
既有FD defer随中断执行；SetComplete仍只在真正成功后运行。不额外删除源文件、退休metadata或退款。
既有下载次数/流量仍按受理尝试记账，不改为成功下载才扣减。

WASM的ReadableStream初始化/读取失败必须调用controller.error，让实际reader.read拒绝；
页面catch取消输入并abort输出，finally清除busy。不能仅显示错误后把两个流悬挂，也不能close失败附件。
保留现有StreamSaver、同源service worker与window.writer接口，不替换加密或下载协议。
浏览器管理的临时partial文件不等于产品源文件；只证明下载失败终态，不承诺擦除客户端磁盘残留。

精确隔离复现、原始日志及评审保留于已核实的自有未公开审查入口。公开只保留必要修复/控制流合同，
不据此宣称已证明远程攻击者利用链、S3、ZIP或全部浏览器均受影响。

## 兼容与回滚

正常附件字节、公开URL、路由、流式内存边界、cipher格式和数据库schema不变；失败不再表现为正常附件完成。
密钥前置错误由200文本变为500，后置错误由正常返回变为传输中断；使用标准HTTP客户端错误处理/重试。
无数据或密钥迁移。回滚前停服务并备份配置/加密材料和数据，限制受影响下载；旧代码会恢复错误完成行为，
不能把回退当作等效修复。本PR不提供修复既有损坏文件的承诺，应从核实备份恢复或重新上传。

## 2026-10-30：052-B取消状态补充

基线0b6b2e2。本地128KiB正常/部分输出取消与真实HTTP/1首字节后客户端取消合同已首次GREEN，现有服务器ErrAbortHandler路径不需额外生产修改。
独立真实WASM/Node24原生流模块合同确认：cancel已经settled后，先前在途Read仍可返回，旧代码继续操作已关闭controller并使运行时异常退出。
精确负例、设置失败与同合同GREEN留自有未公开安全草稿；这是受控模块边界证据，不宣称浏览器或远程攻击链，更未触发静默完整性P0 Gate。

最小选择为每响应独立atomic取消标记：cancel先Store，再Close响应体；初始化reader和每次Read返回后检查标记，再决定是否操作controller。
这不改变未取消的n/err/EOF处理、加密协议、密钥、Promise API、数据格式或公开路由；已取消的body不会再被正常close/enqueue。
Close仍随worker返回执行，不新增锁、队列或加密格式。回滚取消标记会恢复已验证的运行时异常风险，无数据/schema迁移。
浏览器页面writer取消传播、真实原生下载取消和新增截断负例仍需各自实测，不能以模块PASS替代；当前HTTPS临时证书被浏览器工具拒绝，等待用户手动处理，未旁路验证或安装信任。

## 2026-10-30：M5-FIX-03 下载与 ZIP 终态补充

同一失败终态合同扩展到本地原始下载、S3 代理/强制解密和 ZIP。S3 SDK 层返回错误并传递请求取消；HTTP 层在未发送附件时返回通用 500，已开始输出则使用 `http.ErrAbortHandler`，不以 `false` 触发外层重定向。校验已知长度及实际读写计数，保留本地旧 metadata 中 0 表示未知长度的兼容行为。

ZIP 仅在所有成员、central directory、最终 Flush 和请求状态均成功后完成成员 guard；成员或封档失败不通过 defer Close 补写成功目录，不追加错误文本、不提前完成已输出的成员。Close 成功后的最终传输 Flush 仍可能失败；此时中断并保留 guard，不承诺追回已交给底层的 footer。失败沿用既有 guard 超时与尝试计数，不删除源、退休 metadata 或退款。完整的 304/412/416 等条件/Range 响应仍释放 guard，含义是该 HTTP 响应结束，不宣称已交付文件。

本次真实 loopback HTTP、SDK、race 与 Chrome 下载正负例的范围、RED/GREEN 和限制见 [FIX-03 报告](../m5/FIX-03-REPORT.md)。这不补记上述 HTTPS/WASM 跳过项为 PASS，也不外推为真实云 S3、HTTP/2 或所有浏览器组合已验证；不改变密文格式、公开路由或授权模型。
