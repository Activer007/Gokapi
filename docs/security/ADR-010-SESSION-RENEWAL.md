# ADR-010：单进程会话续期与撤销

SEC-021；基线 aff864aa48a77fc795ad91d2f3a4381b8d5afe59，2026-10-28。遵循 M2-GOAL 的个人 VPS / 单进程范围。

## 决策与不变量

续期仅可替换数据库中仍存在、未过期且与已读取记录一致的会话。同一原记录只能成功替换一次；已完成的撤销不能被旧记录续期恢复。用户/全局撤销若在续期之后取得执行权，必须同时删除该续期产生的新记录。正常续期与不同用户会话保留正例。

在 database 门面使用一个进程内互斥锁，协调 SaveSession、RotateSession、DeleteSession、DeleteAllSessions、DeleteAllSessionsByUser。RotateSession 在锁内重新读取并比较记录、删除旧记录、保存新记录；成功后才发送 Cookie。复用两种 provider，不增加接口方法、Lua 脚本、schema、会话代际表或外部服务。锁只保护低频会话变更，不覆盖文件传输或每个会话读取。异常使用已有 provider 错误处理；先删旧再存新，存储故障可能要求重新登录，不应产生两个已交付的凭据。

## 兼容、迁移和回滚

保留 session_token 名称、随机 ID 长度、HttpOnly/Secure/SameSite、12 小时续期点、内置登录 30 天寿命和既有 OAuth 期限计算。已有数据库与 Cookie 可直接读取，无数据迁移；页面/WASM、公开 API、文件和密码哈希不变。

同一旧 Cookie 的并发续期只有一个成功，其余按既有未认证路径处理，不发送覆盖成功 Cookie 的空值。浏览器可能需要重试或重新登录。不要添加前端框架来掩盖这一认证结果。

升级采用单进程停止/启动，按常规备份配置和数据库，无需修改备份内容。回滚代码并重启即可读回同一 schema，但会恢复旧续期语义；回滚后应撤销全部现有会话并要求重新登录，避免将回滚当成持续修复。当前尚未部署，不操作生产数据。

## 有意保留的范围

这不是跨进程事务或崩溃恢复协议。已完成授权的非续期请求可结束。Logout 只撤销它提交的具体 ID；若另一请求已完成轮换且客户端随后提交旧 ID，不追踪新旧 ID 的会话家族。用户/全局撤销则覆盖已存的新记录。新密码/OIDC 登录验证与新会话创建不是本次全程事务；后续请求仍检查当前用户。多实例、身份迁移、长传输抢占与实时数据库故障注入未由本次证明。

## 验证

隔离 SQLite/miniredis 状态合同覆盖正常、过期、撤销、记录变化及并发单次续期。门面测试覆盖续期先执行时的用户/全局撤销，并检查另一用户作用域。私密 HTTP 合同通过测试 Redis 传输屏障运行实际 session 验证/注销函数与网络 Cookie，不改生产验证路径；它不是实际浏览器或真实 Redis 部署证明。原始材料保留在私密评估中，公开只保留必要回归。命令、失败与最终结果见 TEST-REPORT。
