# ADR-007：取消预约与删除重试

状态：SEC-032，待合并；2026-10-28，基线 8377de414a8a07ab1019397470f9547a206c2715。

## 决策

取消只处理当前请求仍有效的预约。预约检查、本地临时文件删除和预约释放在同一锁内完成；文件删除失败时保留预约，并返回不含内部路径的错误。回调只执行本地删除，不得递归访问预约包。

成功取消、重复取消以及尚未上传分片时的取消仍返回 200。未知或无效预约按幂等空操作处理。真正的删除失败返回既有 JSON 错误结构和 500，调用者可在预约有效期内重试。

## 兼容与回滚

保留 API 参数、页面/WASM、SQLite/Redis schema、用户标识和加密格式。预约仍为进程内状态；升级重启与此前一样需要重新开始未完成上传，没有数据格式迁移。删除仅针对取消的临时分片，不改变已发布文件和 S3 对象的删除实现。

回滚代码并重启即可，无需数据转换。已删除的临时分片不能靠回滚恢复，客户端需要重新上传。当前没有部署或生产数据操作，测试均使用隔离副本。

## 限制

锁内的本地删除可能短暂阻塞其他预约；本项不声称高延迟挂载上的性能保证。删除失败重试仍受预约到期和清理规则限制。已通过授权的在途写入、分片完成及异步任务与取消的竞争，属于另行验证的生命周期边界。

发布分支仅包含必要修复、单元回归和兼容说明；完整 API 矩阵与 RED 材料留在私密安全审查记录中。M2 其他验收项保持开放。
