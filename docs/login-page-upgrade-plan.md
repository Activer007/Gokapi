## 1. 目标和范围

将当前单一居中登录卡片升级为“左侧登录表单 + 右侧品牌插画”的横向整体面板，沿用全站深灰背景、蓝色强调和系统字体。增强品牌识别，保持登录直接、清晰。

本轮仅覆盖本地登录页面及其错误/提交状态，不把新布局扩散到下载、安装、改密等其他页面。忘记密码仍进入现有恢复说明；OIDC/代理认证等分支保留原有入口和跳转，不虚构新的登录方式。

本文件保留设计依据，末尾记录实施结果。实施基线为 master@29aaa8c，保留主线版本 2.16.0，不部署或发布 Release。

## 3. 页面设计

### 布局与层级

- 顶部沿用真实 `PublicName`、中文/English；不固定写死 SupaShare。浏览器 Title、页脚说明/链接与版本继续来自配置和现有模板。
- 主体在正常文档流中居中，最大宽约 1344px，桌面左右留白约 32–48px。
- 横向面板左右约 45:55；表单最小可用宽度约 360px。外层统一 10–12px 圆角与细边框，内部不再套一张带边框的卡片。
- 左侧从上到下：登录标题、现有帮助文字、用户名、密码、错误区、主登录按钮、忘记密码。
- 右侧只放无文字的品牌插画。图片与容器等高，以固定比例/裁剪适配；表单高度由内容决定，不能为了图片比例截断错误信息。
- 面板上方保留第 3 张简短标题的设计位置，建议双语词条：“连接文件，连接协作。” / “Connect files. Connect collaboration.”。作为普通文字实现，不能烧进图片，也不能替换用户站点名。
- 表单内边距起始值 40–48px；普通文本约 15–16px，标题约 28–32px，输入/按钮至少 44px 高。复用 `--ss-*` 变量，不把明亮配图的蓝色直接用于小号文本。
- 不增加注册、社交登录、记住我、安全认证徽章、广告式功能列表或动画轮播。首版不加密码显示切换等额外功能。

### 桌面尺寸与可访问性

- 1440×900：主要布局验收尺寸，完整横向面板与页脚清楚可见。
- 1920×1080：限制内容宽度，避免图片和输入框无限拉宽。
- 1280×720：压缩垂直留白及表单内边距，必要时页面自然滚动；不采用固定高度/绝对定位页脚。
- 桌面窄窗口及高缩放：先缩减/隐藏装饰图片，保留表单宽度和操作。布局响应不能更改既有手机/平板访问限制。
- 键盘顺序按实际 DOM：语言/品牌、用户名、密码、登录、忘记密码。图片使用空 alt，不进入 tab 顺序，不播报随机变化。
- 使用真实 label、既有 autocomplete 和明显焦点；错误不只用颜色表达。初始页面不抢焦点干扰自动填充，错误关联到表单且保持提示可读。
- 长 PublicName、中文/英文长提示、多条页脚链接均能换行/截断并保留可访问全文。

1. 原稿永久保留在 docs，不覆盖或删除。用户已允许后续裁剪和压缩。
2. 原稿实际为 1381×1139，链条图为 1382×1138；统一导出 1280×1056（40:33）WebP，不拉伸变形，只做必要的等比缩放和轻微中心裁剪。
3. 从 WebP quality 80–85 开始，单张目标不超过 300 KiB；若需要超过 400 KiB，先检查质量/尺寸取舍再记录原因，不以明显色带、模糊边缘换取达标。

5. 运行文件建议 `internal/webserver/web/static/assets/brand/login/*-v1.webp`。文件名带版本以适配缓存；更换内容时更新文件版本，不依赖浏览器猜测缓存失效。
6. 原三张 UI 效果图只是设计依据，绝不能作为网页背景或登录表单的一部分。原稿约 8.61 MiB，运行时仅加载一张压缩图。

## 5. 随机展示行为

采用轻量客户端方案：模板内可扩展资源目录（首版四项），一个登录页初始化函数，不增加 API、配置页面、数据库或服务端会话字段。

| 场景 | 首版行为 |
| --- | --- |
| 新打开登录页或普通刷新 | 从四张图中等概率选一张，允许偶然连续重复 |
| 当前页面输入/聚焦/点击登录 | 图片固定，不定时轮换、不随字段变化重选 |
| 密码错误或 CSRF 过期返回登录页 | 根据模板现有失败标志，尽量复用本标签页上次插画 |
| 切换语言导致重新加载 | 视为新页面加载，可重选；不额外追踪导航来源 |
| 图片请求失败 | 最多尝试一次默认图；默认图也失败则保留深灰装饰区，不循环请求、不影响表单 |
| 存储不可用或数据无效 | 捕获异常并用合法默认/随机索引继续；不阻止登录 |
| 无新增脚本执行 | 保留纯色装饰区域和原有表单行为；不承诺本来未实现的无 JS 登录支持 |

- 仅用 sessionStorage 保存一个受白名单限制的插画 ID，用于失败返回后的稳定显示；不保存用户名、密码、表单值、CSRF、登录 URL 或服务器错误。
- 资源地址由固定本地列表生成，不能将存储内容直接拼接成任意 URL。随机性只用于装饰，不参与认证。
- 先确定图，再设置一次 src，避免默认图与随机图都先下载。失败回退除外。为图片预留尺寸，加载前保持同色背景，避免布局跳动。
- 不预加载另外三张图；不加滑动按钮、轮播定时器、统计埋点或新依赖。
- 小型逻辑可放入现有 `all_public.js`，用登录页独有节点保护，确保其他公共页面无存储操作/图片请求。新增逻辑异常不能影响现有 submitForm。
- 若后续要求强制每次都不同、跨标签记忆或配置自定义图库，另行讨论，首版不引入。

## 8. 不变项、版本与回退

- 保留 CSRF、认证、限流、会话、密码哈希、强制改密和跳转语义；不更改 HTTPS、ServerURL、Docker 或外部下载辅助服务。
